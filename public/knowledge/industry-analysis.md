## 一、行业分析6步法（通用框架）
### Step 1：行业定位
| 维度 | 问题 | 判断依据 |
|------|------|---------|
| 周期类型 | 强/中/弱周期？ | 看行业是否随宏观经济大幅波动 |
| 研究路径 | 自上而下/自下而上？ | 同质化强→自上而下；差异化明显→自下而上 |
| 定价机制 | 政府定价/市场定价/混合？ | 影响利润弹性 |
| 核心驱动 | 需求/供给/政策/成本？ | 决定分析重点 |
### Step 2：景气度判断
**景气周期四阶段**：
| 阶段 | 上行信号 | 顶部信号 | 下行信号 | 底部信号 |
|------|---------|---------|---------|---------|
| 需求 | 需求回升 | 需求过热 | 需求萎缩 | 需求触底 |
| 价格 | 价格企稳 | 价格高涨 | 价格下跌 | 价格止跌 |
| 库存 | 库存下降 | 库存堆积 | 库存上升 | 库存出清 |
| 政策 | 政策放松 | 政策收紧 | 政策紧缩 | 政策转向 |
### Step 3：核心指标分析
| 指标类型 | 常用指标 | 关注方向 |
|---------|---------|---------|
| 需求指标 | 销量/产量、渗透率、增速 | ↑=景气上行 |
| 供给指标 | 产能利用率、新增产能、库存 | 利用率↑=景气好 |
| 价格指标 | 产品价格、毛利率、价差 | ↑=盈利改善 |
| 效率指标 | ROE、ROIC、周转率 | ↑=经营效率提升 |
| 成本指标 | 原材料成本、人工成本 | ↓=成本压力缓解 |
### Step 4：收入与成本拆解
```
利润 = (价格 × 销量) - (固定成本 + 变动成本) - 三费 - 税
```
**关键问题**：
1. 收入主要靠量还是靠价？
2. 成本中哪部分弹性最大？
3. 利润对哪个因素最敏感？
### Step 5：估值方法选择
| 估值方法 | 适用场景 | 不适用场景 |
|---------|---------|-----------|
| P/E | 稳定盈利企业 | 亏损企业；周期股顶部 |
| P/B | 熊市重置成本底线 | 对盈利能力反映不足 |
| DCF | 现金流稳定的公用事业 | 受终值假设影响大 |
| EV/EBITDA | 重资产行业 | 无法反映汇兑收益 |
| NAV | 房地产企业 | 假设多，信息不对称 |
| P/EV+NBVM | 寿险公司 | 精算假设敏感 |
| 市值/产能 | 钢铁等产能型行业 | 产品结构差异大时 |
### Step 6：估值计算与结论
1. 选择1-2种主方法
2. 确定关键假设（乐观/中性/悲观）
3. 计算估值区间
4. 对比当前股价
5. 给出投资建议

## 三、航空机场行业
### 3.1 行业特点
- **同质性**：产品无本质差别（人或货物的位移）
- **瞬时性**：服务不可储存，边际成本几乎可忽略（易造成价格战）
- **核心是"体验"**：安全性、准时性、便捷性、舒适性
### 3.2 核心指标
**航空公司**：
| 指标类别 | 关键指标 |
|---------|---------|
| 产能 | ATK（可用吨公里）、ASK（可用座公里） |
| 产量 | RTK（收入吨公里）、RPK（收入座公里） |
| 效率 | 载运率、客座率(PLF) |
| 单位 | 客公里收入（衡量票价）、座公里收入、吨公里成本 |
**机场**：飞机起降架次、旅客吞吐量、货邮吞吐量、非航收入占比（衡量管理水平）
**需求预测公式**：旅客周转量增速 = GDP增速 × (1.3~1.8)
### 3.3 收入与成本
**航空公司成本**：航油是最大成本且不可控（三大费用：航油、人工、折旧）
**机场收入**：
- 航空性收入（5项）：旅客服务费、起降费、安检费、停场费、廊桥费
- 非航收入：租赁、广告、货站等（国际先进机场非航占比>50%）
### 3.4 关键驱动因素
| 因素 | 影响 |
|------|------|
| **油价** | 航油占成本最大比重；每涨10美元/桶，航油成本+约5% |
| **汇率** | 人民币升值利好（汇兑收益+成本下降+推动出境游）；升值1%，三大航利润+约3-5亿 |
| **供求** | 运力投放（飞机引进/淘汰）、客座率 |
### 3.5 估值方法
| 方法 | 适用 | 注意 |
|------|------|------|
| DCF | 机场（经典方法） | 受终值影响大 |
| P/E | 牛市+景气时航空公司 | 受主观影响 |
| P/B | 熊市/不景气时 | PB=1为重置成本底线 |
| EV/EBITDA | 出现亏损时 | 无法反映汇兑收益 |
### 3.6 投资逻辑
- **航空公司**：高Beta行业，适合趋势性投资；牛市选龙头+弹性最大
- **机场**：增长稳定、现金流充沛，典型防御性品种
- **反向特征**：弱市机场跑赢大市；牛市航空运输爆发力远超机场

## 四、保险行业
### 4.1 行业特殊性
- 盈利周期长，收入与费用时间不匹配
- "三差"是利润来源：**死差**（实际vs预定死亡率）、**费差**（实际vs预定费用率）、**利差**（实际投资收益率vs预定利率≤2.5%）
### 4.2 三种评估准则
| 准则 | 目的 |
|------|------|
| SAP（法定） | 保证偿付能力，保守假设 |
| GAAP（公认会计） | 了解获利能力 |
| **EV（内含价值）** | 理解公司价值，**寿险核心** |
### 4.3 估值体系
```
评估价值(AV) = 内含价值(EV) + 新业务价值(NBV) × 新业务价值倍数(NBVM)
内含价值(EV) = 调整后净资产 + 有效业务价值(VIF)
```
**为什么用NBVM而不用PE**：寿险保单期限长→利润叠加效应→PE估值不适用
### 4.4 关键财务指标
**利润核心**：营业收入 = 已赚保费 + 投资收益；投资收益是影响利润的主要科目
**波动性排序**：σ(EPS) > σ(净资产) > σ(内含价值) > σ(新业务价值) → **新业务价值最稳定**
### 4.5 行业驱动因素
- 个险增长与社会零售品总额增长同步
- 银保增长与上证指数负相关
- **利差周期比利率周期对保险股走势更有预见性**

## 六、电力行业
### 6.1 行业属性
- **半周期**：下游一半是周期性行业（钢铁、有色等），一半非周期
- **半公用事业**：电价受管制，行业有较大外部性
### 6.2 核心三要素
| 要素 | 决定方 | 关注点 |
|------|--------|--------|
| **电价** | 政府主导 | 政策意图、成本、CPI、供需 |
| **煤价** | 市场主导 | 煤炭供求、入炉价 |
| **利用小时** | 供需决定 | 用电需求+装机增速 |
**敏感度**：电价:煤价:利用小时 ≈ 2:1:1
### 6.3 成本构成
- **火电**：煤炭占70%→近似加工型企业
- **水电/核电**：可变成本低，折旧和财务费用占比大→前期压力大，后期现金流充裕
### 6.4 估值方法
| 方法 | 适用 |
|------|------|
| **DCF** | 水电（经典） |
| **P/E** | 牛市定价（水电PE高火电约5倍） |
| **P/B** | 熊市底线（PB=1为重置成本底线） |
**行业运行区间**：盈利和股价都在P/B箱体内运行（PB=1~3之间）
### 6.5 关键判断指标
- 毛利率变动趋势（火电盈利能力核心）
- 度电成本 = (主营成本+期间费用) / 年均电量
- 重点区域市场分析（判断利用小时）

## 七、电子行业
### 7.1 行业特征
- **显著周期性**，以费城半导体指数（SOX）为标志
- 当前周期驱动：AI算力需求
### 7.2 产业链
```
IP → Fabless Design → Foundry(晶圆代工) → Packaging & Testing(封测) → 终端市场
```
### 7.3 核心跟踪指标
| 指标 | 含义 |
|------|------|
| **产能利用率** | 反映供需紧张程度 |
| **毛利率** | 盈利能力核心 |
| **库存水平** | 供需平衡信号 |
| **订单提前期(Lead Time)** | **最灵敏的周期信号** |
| **Capex vs 销售额** | 产能扩张节奏 |
### 7.4 周期信号判断
**见顶6大信号**：
1. Lead Time缩短至10-12周
2. 供货不足现象出现
3. 分析师乐观情绪蔓延
4. 产能利用率接近满载
5. 资本开支大幅增加
6. 终端需求增速放缓
**见底5大信号**：
1. Lead Time缩短至2-4周
2. 行业裁员潮
3. "行业无成长论"盛行
4. 库存开始去化
5. 资本开支收缩
### 7.5 投资核心理念
> **Cliff Diving（悬崖跳水）**：在行业低谷时入场，而非等待景气回升确认。
### 7.6 半导体景气传导路径
```
GPU/ASIC → 存储芯片 → 光通信芯片 → CPU → 配套元器件
```
**紧缺环节**：ABF载板 > 内存接口芯片 > 三次电源VRM > 高多层PCB > 先进封装

## 八、房地产行业
### 8.1 行业特点
- **资金密集型**、**周期性明显**、**区域差异大**、**政策敏感性强**
### 8.2 核心指标
**需求端**：
| 指标 | 含义 |
|------|------|
| **房价收入比** | 最重要的需求端预警指标 |
| **月供/月收入** | 衡量购房负担能力，不应超过50% |
| **购房目的结构** | 自住/投资/投机占比 |
**供给端**：土地购置面积（先行2-3年）→新开工面积（先行1-2年）→竣工面积
### 8.3 NAV估值法（行业核心方法）
```
NAV = Σ(各项目现金流折现值 × 权益比例) + 非核心资产 + 现金 - 净债务
```
**关键假设**：价格（影响最显著）、折现率（WACC）、成本、开发进度
### 8.4 周期判断框架
```
资金宽松 → 销售回暖 → 地王出现 → 加速拿地 → 加快开工 → 供应上升
→ 供不应求 → 房价上涨 → 政策收紧 → 资金紧张 → 销售萎缩 → 土地流拍
```
### 8.5 风险管理
- **关注经营性现金流**：长期负现金流需警惕
- **有息负债率**：衡量财务安全边际
- **香港教训**：房价脱离居民承受力→泡沫必然破裂

## 十、钢铁行业
### 10.1 行业属性
- **投资拉动型**，与固定资产投资增速高度相关
- **完全竞争**，CR5约20%
- 低端品种同质化严重，高端品种差异化
### 10.2 核心指标
**需求分析**：单位GDP耗钢量估算法 / 固定资产投资量估算法 / 行业加总法
**关键关系**：
- 钢价与PPI趋势基本契合
- 钢价与M1/M2剪刀差基本吻合
- 平均钢价能"预测"FAI增速趋势
### 10.3 成本构成
| 成本项 | 占比 |
|--------|------|
| **铁矿石** | **35%-50%** |
| **煤炭** | **15%-20%** |
| 电力 | 4%-5% |
| 折旧 | 4%-5% |
> **核心变量：矿石和煤炭成本波动较大，其他相对稳定**
### 10.4 估值方法
| 方法 | 适用 |
|------|------|
| PE | 国内主要方法；钢铁板块PE相对大盘长期在0.6-0.8倍 |
| PB | PB=1为重置成本底线 |
| EV/EBITDA | 国外常用，适合重资产 |
| 市值/产能 | 吨钢市值：普通钢3000-5000元/吨，特钢5000-8000元/吨 |
### 10.5 投资时机
**景气低点介入（最佳）**：全行业不盈利或亏损、短期价格成本倒挂、宏观紧缩趋于放松、社会库存极低、股票破净
**接近景气高点抛出**：行业盈利剧增、经济增速过快可能招致调控、价格高涨影响下游需求

## 十一、公路铁路行业
### 11.1 公路行业
**核心特点**：固定性（自然垄断）、期限性（收费25-30年）、现金流稳定、防御性强
**收入公式**：
```
通行费收入 = Σ (车流量OD × 收费标准R × 里程L)
```
**核心变量**：车流量（最核心）、收费标准（相对固定）、计重收费
**风险因素**：分流风险、经济低迷（货车流量与经济增长完全正相关）、养护费用（8-10年大修）、政策风险
### 11.2 铁路行业
**特点**：网络化运营、政企合一、运价管制
**核心指标**：客货运量（与GDP保持同步，周转量年均增幅为GDP增速的0.8-1倍）
### 11.3 估值方法
| 方法 | 重要性 | 关键参数 |
|------|--------|----------|
| **DCF（最重要）** | ★★★★★ | 经营期限内车流量/收入/成本预测、WACC、大修假设 |
| P/E | ★★★ | 适用于盈利稳定公司 |
| EV/EBITDA | ★★★★ | 消除折旧方法差异影响 |
### 11.4 投资逻辑
**公路四大核心逻辑**：
1. 中国经济增长的最好杠杆
2. 现金流稳定，周期性不大
3. 有资产增值潜力
4. 经济低迷时防御性强

## 十二、电力设备行业
### 12.1 行业特点
- **投资驱动**：投资造成的需求是分析最关键要素
- **政策影响大**：行业景气度受政策影响显著
- **下游议价能力强**：五大发电集团+两大电网
### 12.2 产业链
| 方向 | 代表领域 |
|------|---------|
| 发电侧 | 风电机组、核电设备、光伏设备 |
| 电网侧 | 变压器、开关、直流换流阀、控制保护 |
| 用户侧 | 节能环保、铁路电气 |
### 12.3 三大投资方向
| 方向 | 核心逻辑 | 代表领域 |
|------|----------|----------|
| **低碳能源** | 向新经济转型 | 核电(4000亿+)、光伏、风电 |
| **电网升级** | 投资趋向"哑铃型" | 特高压/直流、配电网 |
| **轨道交通** | 黄金发展期 | 电气化铁路+城市轨道交通 |
### 12.4 子行业投资策略
| 子行业 | 阶段 | 投资要点 |
|--------|------|----------|
| 核电 | 快速成长期 | 国产化率提升+市场容量巨大 |
| 光伏 | 高成长期 | 全球装机高增长+国内市场启动 |
| 储能 | 导入期 | 2020年市场需求1.1亿千瓦 |
| 输变电 | 成熟期 | 高端市场强者恒强+特高压 |
| 二次设备 | 成长期 | 智能电网驱动+年均增速20%+ |
### 12.5 成本关注
**关键原材料**：铜（电缆、变压器绕组）、铝（导线）、钢材（塔架）、硅钢（变压器铁芯核心）
