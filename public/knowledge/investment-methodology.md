## 一、投研方法论总览
### 1.1 三大研究方法
| 方法 | 适用行业 | 核心逻辑 |
|------|---------|---------|
| **自上而下法** | 同质化强的行业（航空、电力、钢铁） | 先选行业，后选公司；把握行业拐点 |
| **自下而上法** | 差异化明显的行业（品牌零售、水电、传媒） | 注重个案研究，公司特质重于行业周期 |
| **混合方法** | 多数行业 | 先自上而下判断景气度，再自下而上选个股 |
### 1.2 通用分析框架（六维度）
```
1. 行业概况：产品特点、产业链、企业分类
2. 核心指标：需求/供给/效率指标
3. 收入与成本：构成、敏感性、利润驱动因素
4. 定价机制：政府定价 / 市场定价 / 混合
5. 估值方法：PE/PB/DCF/EV-EBITDA/NAV等
6. 投资逻辑：周期判断、选股标准、买卖时机
```
### 1.3 景气周期四阶段判断
| 阶段 | 信号 | 投资策略 |
|------|------|---------|
| **上行** | 需求回升、价格企稳、库存下降、政策放松 | 提高配置，选龙头+高弹性 |
| **顶部** | 价格高涨、产能扩张、库存堆积、政策收紧 | 逐步减仓，关注拐点 |
| **下行** | 需求萎缩、价格下跌、库存上升、全行业亏损 | 降低配置，选防御品种 |
| **底部** | 破净、产能出清、政策转向、龙头逆势扩张 | 逢低布局，等待拐点 |

## 二、技术分析方法论（钱多多体系）
### 2.1 动态止盈法
| 要素 | 内容 |
|------|------|
| **适用场景** | 持仓个股出现短期冲高后回撤 |
| **触发条件** | 股价从近3-5天最高点回撤3%-5%（20CM股适用5%，一般个股3%） |
| **操作动作** | **部分止盈**，非清仓；按仓位轻重止盈1/4或1/3 |
| **后续规则** | 执行一次后，若股价不跌破关键均线（如5日线），持仓部分继续持有 |
### 2.2 关键K线分析法
**适用场景**：判断一段走势中的关键支撑/压力位
**关键价格位（重要性递减）**：
| 优先级 | 价格位 | 含义 |
|--------|--------|------|
| 1 | **开盘价** | 最强支撑/压力。实质性破位=跌破后一去不返 |
| 2 | **收盘价** | 重要支撑/压力 |
| 3 | **50%分位** | 多空生命线。上方安心，跌破需控仓 |
**判断标准**：
- 股价在关键K线开盘价上方 = 强势区
- 股价在关键K线开盘价下方 = 弱势区
- 多条关键K线价格位重叠 = 强支撑/压力区
### 2.3 均线组买卖点判断
| 类型 | 条件 | 操作 |
|------|------|------|
| **第一类卖点** | 乖离率达到30 | 减仓信号 |
| **第二类卖点** | 跌破短期均线组（5日、8日均线） | 明确减仓控仓 |
| **买点** | 回踩关键均线（如60日线）并企稳 | 可能构成买点 |
**乖离率特殊规则**：
- 应用于宽基指数ETF时，**阈值减半**（指数波动小于个股）
- 短周期（30分钟线）上慎用或不用乖离率
### 2.4 缺口理论
| 规则 | 内容 |
|------|------|
| **3天回补法则** | 向下跳空缺口产生后，**3个交易日内必须回补** |
| **未回补后果** | 调整期至少延长2-3天 |
| **延长规则** | 延长后仍未反包，可能继续延长2-3天 |
**缺口分类**：
| 缺口类型 | 特征 | 操作 |
|---------|------|------|
| 突破缺口 | 放量突破关键位置 | 跟进买入，缺口成强支撑 |
| 持续缺口 | 趋势中段出现 | 持仓不动，缺口为加仓点 |
| 衰竭缺口 | 趋势末端出现 | 警惕反转，不宜追涨 |
| 普通缺口 | 震荡区间内 | 通常3天内回补，高抛低吸 |
**口诀**："缺口三天补，不补则延；延而不反，继续观望。"
### 2.5 神奇数字（量化压力/支撑位）
**原理**：量化交易模型常用整数对称位作为算法交易节点，形成实际压力或支撑。
| 类型 | 示例 |
|------|------|
| 重复数 | 11.1、8.88 |
| ABBA型 | 12.21 |
| ABA型 | 12.1、1.21 |
| 整数 | 35.00 |
| .50 | 17.50 |
| 顺子 | 12.34、43.21 |
**操作**：在神奇数字价位附近观察突破力度，无法快速突破则受阻。
### 2.6 成交量验证原则
| 场景 | 成交量要求 | 判断 |
|------|-----------|------|
| **突破关键位置** | 必须放量，通常需要**倍量** | 无量突破多为假突破 |
| **回踩关键支撑** | 应该缩量 | 放量跌破=有效破位 |
| **关键K线形成** | 必须放量 | 缩量阳线=弱势反弹 |
**量价关系速查**：
| 价格 | 成交量 | 含义 | 操作 |
|------|--------|------|------|
| 涨 | 放量 | 健康上涨 | 持仓/跟进 |
| 涨 | 缩量 | 上涨乏力 | 警惕回调 |
| 跌 | 放量 | 恐慌抛售 | 减仓/离场 |
| 跌 | 缩量 | 惜售/衰竭 | 观望，等企稳 |
### 2.7 斐波那契时间窗口
**三套系统**：
| 系统 | 用途 | 方法 |
|------|------|------|
| **周线窗口** | 中期趋势转折 | 从重要高/低点数起，第8/13/21周为关键窗口（允许±2周误差） |
| **日线3天/5天法则** | 短期回补判断 | 跌破60日线后3天内必须站回，否则看第5天；个股可缩短为2/3天 |
| **月线大格局** | 仓位管理参考 | 守住5月均线=趋势健康；站回上月开盘价=震荡偏多 |
**多周期共振操作流程**：
```
第一步：看月线 → 定大方向（5月均线是否守住）
第二步：看周线 → 卡时间窗口（斐波那契第8/13/21周）
第三步：看日线 → 抓短线回补点（3天/5天法则）
第四步：看30分钟 → 精细买卖点（均线系统）
```
### 2.8 ETF与个股联动策略
```
第一步：先上车 → 看好板块但无个股目标时，先买行业ETF
第二步：买ETF → 出现短期买点时建立部分仓位
第三步：研究切换 → 同时深入研究寻找板块内优质个股
第四步：仓位转移 → 个股出现回调买点时，将ETF仓位逐步转移到个股
```
### 2.9 仓位管理原则
| 市场状态 | 建议仓位 | 操作思路 |
|---------|---------|---------|
| 强势上攻（量能>2.5万亿+指数上行） | 7-8成 | 适度加仓 |
| 正常震荡 | 6-7成 | 持股做结构 |
| 弱势企稳（均线从向下转粘合） | 4-5成 | 逢低布局 |
| 明显下行（均线朝下） | 3-4成 | 防守为主 |
| 极端弱势（大盘+个股均线均朝下） | 2成以下 | 等待企稳 |
**量能参考**：
| 量能水平 | 市场含义 |
|---------|---------|
| <2万亿 | 缩量，市场低迷 |
| 2-2.5万亿 | 正常水平 |
| 2.5-3万亿 | 活跃水平 |
| >3万亿 | 高风偏，牛市特征 |
### 2.10 多周期应用规则
| 周期 | 用途 | K线数/天 | 注意 |
|------|------|---------|------|
| **日线** | 主要周期，中短期趋势 | 1根 | 标准周期 |
| **30分钟线** | 精细短线操作 | 8根 | 可用均线逻辑 |
| **周线** | 大级别趋势 | — | 辅助震荡区间 |
| **月线** | 长期趋势 | — | 主要用于仓位管理 |
**重要原则**：固定使用一套方法，避免多周期多指标信号冲突。

## 三、K线分析方法论
### 3.1 抄底两种形态
| 形态 | 描述 | 优势 | 缺点 | 适用对象 |
|-----|------|------|------|---------|
| **三天不新低** | 连续3个交易日不再创新低 | 更可能买到低点 | 确定性低 | 超短线（博1-2天反弹） |
| **均线趋势粘合朝上** | 均线从向下转向粘合，再朝上 | 确定性更高 | 难买在最低点 | 波段投资者 |
### 3.2 双向确认规则
```
大盘 + 个股 同时出现上述形态之一 → 确定性较高 ✓
仅单向出现 → 确定性不高 ✗
```
| 场景 | 操作建议 |
|-----|---------|
| 大盘向下 + 个股均线朝下 | **不抄底** |
| 大盘企稳 + 个股均线朝下 | 谨慎，确定性不高 |
| 大盘企稳 + 个股均线朝上/粘合 | 可以参与 |
| 大盘向上 + 个股均线朝上 | **确定性最高** |
### 3.3 K线组合形态速查
**反转形态**：
| 形态 | 特征 | 信号 | 操作 |
|------|------|------|------|
| 早晨之星 | 阴线+十字星+阳线 | 底部反转 | 买入 |
| 黄昏之星 | 阳线+十字星+阴线 | 顶部反转 | 卖出 |
| 看涨吞没 | 小阴线+大阳线完全吞没 | 底部反转 | 买入 |
| 看跌吞没 | 小阳线+大阴线完全吞没 | 顶部反转 | 卖出 |
| 锤子线 | 下影线长，实体小，下跌末端 | 底部反转 | 观望/轻仓买入 |
| 红三兵 | 连续三根小阳线，逐步走高 | 上涨延续 | 持仓/加仓 |
| 三只乌鸦 | 连续三根小阴线，逐步走低 | 下跌延续 | 减仓/离场 |
**持续形态**：
| 形态 | 特征 | 操作 |
|------|------|------|
| 上升三法 | 大阳线+3小阴线（未破大阳线低点）+大阳线 | 持仓/加仓 |
| 下降三法 | 大阴线+3小阳线（未破大阴线高点）+大阴线 | 减仓/观望 |
### 3.4 K线分析实战 Checklist
**买入前检查**：
- [ ] 是否处于关键K线开盘价上方？
- [ ] 回踩时是否缩量？
- [ ] 是否出现止跌K线形态？
- [ ] 成交量是否配合（突破放量、回踩缩量）？
- [ ] 多周期是否共振？
- [ ] 大盘是否同步企稳？
**卖出前检查**：
- [ ] 是否跌破关键K线开盘价且一去不返？
- [ ] 是否出现顶部K线形态？
- [ ] 是否放量下跌？
- [ ] 乖离率是否过大（超过30需警惕）？
### 3.5 三日反包法则
- 关键中阴线/大阴线出现后，**三天内**必须收复至少**50%**跌幅
- 第二天如果继续跌，第三天全反包概率**大幅下降**
- 三天内未反包50% → 趋势延续下行，需减仓/离场
### 3.6 9:45强弱判断法则
**规则**：每日9:45，观察上证指数与关键位置的比较：
- 9:45站上关键位 → 当日大概率收阳
- 9:45未站上关键位 → 当日大概率偏阴
**关键位置确定方法**：
- 从最近的历史重要K线四个价格中找
- 昨天阳线 → 向上找压力位
- 昨天阴线 → 向下找支撑位

## 四、钱多多投资课程15大核心框架
### 框架1：景气增速30%分水岭理论
**适用场景**：判断高增长公司业绩增速回落时是否应离场
**核心逻辑**：增速高位回落 ≠ 行情终结，关键看是否跌破30%分水岭
| 增速状态 | 判断 | 操作 |
|---------|------|------|
| 增速回落但维持>30% | 高增长逻辑未受系统性冲击 | **持股不动** |
| 增速回落至0-30% | 超额收益收敛 | **适当减仓** |
| 增速降至负增长 | 高增长逻辑瓦解 | **离场** |
**注意**：30%阈值适用于科技制造类高估值品种，低估值周期品不适用。
### 框架2：AI渗透率"位置感"方法
**适用场景**：判断AI产业行情处于什么阶段
| 对标维度 | 当前AI | 历史对标 | 结论 |
|---------|-------|---------|------|
| 美国个人生成式AI普及率 | 28.3% | ≈ 1998年互联网普及率30.1% | 尚未走完最快阶段 |
| A股AI+业务公司占比 | 21% | 互联网+高峰30%，新能源+高峰26% | 仍有提升空间 |
**核心结论**：**当前AI大周期距离终场仍有距离，但已进入下半场（应用端快速扩散阶段）**
### 框架3：春季躁动日历效应
**适用场景**：每年11月-次年3月判断是否参与春季躁动行情
**三类催化 → 三种风格**：
| 催化类型 | 占优风格 |
|---------|---------|
| 经济基本面向好 | **顺周期**占优 |
| 宏观政策超预期 | **政策受益/高弹性板块**占优 |
| 风险扰动缓和+流动性宽松 | **景气/产业趋势方向**占优 |
**节奏特征**："价值搭台，成长唱戏"——12月大盘低估值占优，春节后至两会前小盘科技成长占优。
### 框架4：行业比较四步框架
```
位置（行业处于什么阶段？）→ 空间（还有多大空间？）→ 追踪（如何持续跟踪？）→ 坐标（如何在组合中定位？）
```
| 策略类型 | 选股逻辑 | 目标 |
|---------|---------|------|
| **景气策略** | 选择处于回升→扩张期的产业链 | 获取β收益 |
| **反转策略** | 高需求β链、短期利润承压即将反转 | 提高夏普、控制波动 |
### 框架5：拥挤度分析方法
**适用场景**：判断热门行业/板块是否资金抱团过热
| 信号类型 | 触发条件 | 含义 |
|---------|---------|------|
| 行业风险 | 拥挤度提升倍数超越历史高点 | 资金抱团过热，警惕回调 |
| 短期调整 | 全A拥挤度出现高极值后回落 | 短期调整信号 |
| 布局信号 | 拥挤度消化、龙头比价回落至低位 | **二次布局机会** |
**关键**：拥挤度是"分母端"因素，分子端（景气/产业趋势）才是决定大行情持续性的关键。
### 框架6：牛市终结信号多维判断
**四维指标体系**：
| 维度 | 终结信号 | 未终结信号 |
|-----|---------|----------|
| **估值** | 股权风险溢价下破-2σ；PE/PB超越前两轮高点 | 估值仍合理 |
| **交易** | 成交额/换手率超越前四轮牛市峰值抬升倍数 | 仅超越2017年水平 |
| **资金** | 开户数出现高峰；融资买入触及+2σ；爆款基金集中出现 | 缩量，高峰未确认 |
| **量能** | 持续缩量跌破关键水平 | 维持3万亿以上 |
**关键**：多个维度同时触发 → 牛市终结概率大；仅局部触发 → 短期震荡。
### 框架7：有色3x成本定价法
**适用场景**：供给端天然受限的有色金属品种价格目标测算
**规则**：过去十年产量CAGR接近零的品种，稳态价格 = 完全成本 × 3
| 品种 | 十年产量CAGR | 已验证 |
|-----|-------------|--------|
| 钨、、锑 | 负增长 | ✓ 已验证3x |
| 锡 | 0.5% | 待验证 |
| 铜 | 2% | 低增量 |
### 框架8：人民币升值配置四逻辑
| 逻辑 | 机制 | 受益行业 |
|-----|------|---------|
| ①进口成本下降 | 升值降低进口成本 | 煤炭、钢铁、有色、航空 |
| ②外币负债成本下降 | 美元负债成本下降 | 建筑地产链、物流 |
| ③购买力提升 | 居民购买力提升 | 跨境电商、免税、酒店 |
| ④外资审美偏好 | 吸引外资回流 | AI硬件、优势制造业、有色 |
### 框架9：Capex与股价关系
**核心逻辑**：Capex增速回落 ≠ 行情终结，关键看业绩增速是否跌破30%
**判断**：
1. 云和AI业务收入带来的经营现金流增长 > 资本支出增长 → Capex可持续
2. 算力能提升AI性能、tokens的ROI维持可观 → Capex"螺旋上升"
3. 财报季是Capex预期上修的重要窗口
### 框架10：AI投资ROI周期框架
**核心命题**：AI产业链存在阶段性切换——**上半场看Capex，下半场看ROI**
| 阶段 | 市场关注点 | 估值驱动 | 风险特征 |
|------|-----------|---------|---------|
| 上半场 | 资本开支增长 | 渗透率叙事+远期空间 | 怕需求不及预期 |
| 下半场 | ROI、正向现金流 | 利润兑现+现金回报 | 怕入不敷出 |
### 框架11：边际增速的增速框架
**核心命题**：股市炒的不是"还在涨"，而是"涨得更快还是更慢"——看增速的**二阶导数**
- 涨价/业绩仍在增长但增速放缓 → 股价可能已开始下跌
- 涨价/业绩增速重新加速 → 股价可能已开始上涨
- 适用于所有"景气投资"方向（存储、AI硬件、新能源等）
### 框架12：大型IPO流动性虹吸模型
**历史参照（2020年7月中芯国际上市）**：
| 阶段 | 操作 |
|------|------|
| IPO上市前 | 控制仓位，不急于加仓 |
| 上市后1-2天 | 最恐慌时刻，也是最后洗盘 |
| 快则1-2天、慢则一周 | **确定性最高的进场时机** |
### 框架13：业绩披露窗口配置策略
| 时间 | 市场特征 | 配置策略 |
|-----|---------|---------|
| 1月（验证期） | 年报业绩预告密集披露 | 聚焦业绩确定性品种 |
| 2月（空窗期） | 数据空窗 | 可适度放宽至弹性品种 |
| 3月（想象力期） | 预期和想象力主导 | 聚焦产业趋势方向 |
### 框架14：半导体景气度传导分析
**传导路径**：
```
GPU/ASIC → 存储芯片 → 光通信芯片 → CPU → 配套元器件
```
每一轮传导都会带来新一轮紧缺和涨价机会。
**紧缺环节排序**：ABF载板 > 内存接口芯片 > 三次电源VRM > 高多层PCB/CCL > 先进封装
### 框架15：A股"喜新厌旧"迁徙模型
**核心命题**：A股资金不断从"已有业绩但缺乏新鲜感"的老方向，向"有想象空间但业绩尚未验证"的新方向迁徙。
**操作含义**：
- 老方向即使业绩超预期，市场也觉得"没有新鲜感"
- 新方向才有更多想象空间
- **跟随资金迁徙：从大的板块往细分新方向切**

## 五、谈笑间228投资体系补充框架
### 5.1 公募持仓集中度极值监测
**核心**：当单行业持仓占比达到极端水平（如接近半仓），持仓结构本身成为最大的风险因子。
| 指标 | 极值信号 |
|------|---------|
| 单行业持仓占比 | 电子45.5%≈半仓 → 历史级极端 |
| 前二行业合计 | 电子+通信61% → 超六成资金挤两赛道 |
| 单行业超配比例 | 电子超配24%（一季度12%翻倍） |
**经验法则**：当持仓迁移速度突破历史经验上限时，Beta行情的下半场概率大于上半场。
### 5.2 K型分化→再平衡机会识别
**K型结构**：上方极度拥挤（电子45.5%、通信16.3%），下方极度荒凉（食品饮料1.2%、医药2.3%）
**再平衡触发条件**：
| 方向 | 触发条件 |
|------|---------|
| 红利资产 | 筹码压制解除（持仓足够低→抛压衰竭） |
| 金属/化工/建材 | 加息预期被修正 |
| AI应用端 | AI硬件分化→资金外溢→寻找低估值方向 |
### 5.3 K型下方再平衡三重触发信号
> 需要三重信号中至少两个同时出现：
> 1. **筹码压制解除**：持仓降到足够低→抛压自然衰竭
> 2. **预期修正**：此前压制估值的宏观因素出现反转
> 3. **催化事件**：基本面层面出现边际改善信号
### 5.4 ETF净流入排名=大资金风向标
- ETF净流入方向就是机构的选择，不要和大资金对着干
- 每周关注ETF净流入排名，排名前列的方向代表大资金共识
### 5.5 美股"老灯/小灯"分化映射
| 美股信号 | A股映射 |
|---------|---------|
| "小灯"（半导体/存储）跌 | A股存储/半导体/光模块承压 |
| "老灯"（大型科技）涨 | A股大盘价值/科技应用相对稳定 |
需区分映射方向：不是简单的"美股跌A股跌"，而是看**美股哪个方向跌**。

## 六、通用估值方法速查
| 估值方法 | 适用场景 | 局限性 | 计算公式 |
|---------|---------|--------|---------|
| **P/E** | 稳定盈利企业，牛市定价 | 亏损时不可用；受情绪影响 | 股价/EPS |
| **P/B** | 熊市中重置成本底线 | 对盈利能力反映不足 | 股价/每股净资产 |
| **DCF** | 现金流稳定的公用事业 | 受终值假设影响大 | Σ FCF/(1+r)^t + TV |
| **EV/EBITDA** | 重资产行业，亏损时仍可用 | 无法反映汇兑收益 | 企业价值/EBITDA |
| **NAV** | 房地产企业 | 假设多，信息不对称 | 项目价值-负债 |
| **P/EV+NBVM** | 寿险公司 | 精算假设敏感 | 内含价值+新业务价值 |
| **市值/产能** | 钢铁等产能型行业 | 产品结构差异大时不适用 | 总市值/年产能 |
| **SOTP** | 多元化经营企业 | 各业务估值方法需统一 | 各业务分别估值加总 |
**估值决策树**：
```
公司是否盈利？
├─ 否 → 是否重资产？
│       ├─ 是 → EV/EBITDA 或 PB
│       └─ 否 → PS 或 用户价值
└─ 是 → 盈利是否稳定？
        ├─ 是 → PE 或 DCF
        ─ 否（周期股）→ 景气底部用PB，景气顶部谨慎
```

## 七、投资时钟与周期判断
### 7.1 基本面与技术面结合
| 维度 | 方法 |
|------|------|
| 估值参考 | 券商一致性预测（去掉最高最低取平均）计算目标价 |
| 信息验证 | 短期暴涨题材股，查验F10是否有近期机构研报支撑 |
| 逻辑与走势 | 即使中长期逻辑好，若短期技术走势破位，**先尊重市场走势执行风控** |
### 7.2 常见误区
| 误区 | 正确做法 |
|------|---------|
| 单根K线定乾坤 | 需结合位置、成交量、多根K线组合 |
| 忽视位置 | 同样形态在不同位置含义完全不同 |
| 忽视成交量 | 无量阳线/阴线都不可信 |
| 多周期混乱 | 固定1-2个周期即可 |
| 周期股PE陷阱 | 景气顶部PE低便宜，景气底部PE高≠贵 |
### 7.3 核心操作原则
1. **趋势为先**：用60天线判断中期趋势（线上强，线下弱）
2. **方法专一**：熟练掌握并固定使用一套均线交易方法
3. **止损是底线**：任何买入信号都可能失败，必须设定止损位
4. **市场情绪优先**：极端情绪下技术形态可能失效
5. **双向确认**：个股与大盘同步确认，叠加寻找"高一分的确定性"
