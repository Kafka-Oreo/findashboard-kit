## 一、AI与科技产业链
### 1.1 AI产业总体判断
| 维度 | 核心观点 |
|------|---------|
| **产业阶段** | AI渗透率约28.3%（≈1998年互联网），**已进入下半场但距终场仍有距离** |
| **核心主线** | 智能体是2025-2026年确定性主线；算力硬件从训练转向推理 |
| **渗透速度** | 企业端慢于个人端，但整体扩散速度超过行业前期预估 |
| **长期逻辑** | AI产业长期成长逻辑明确，下游落地围绕各类智能体工具展开 |
### 1.2 算力硬件链
#### 核心趋势
| 环节 | 趋势 | 投资含义 |
|------|------|---------|
| **芯片** | 从训练转向推理，专用化（ASIC）加速 | 芯原股份订单逐季加速；终端芯片Q2创历史新高 |
| **散热** | 液冷成标配，多技术路线并行 | 冷板式、浸没式并行发展 |
| **互联** | 高速光模块需求持续扩张 | 800G/1.6T光模块、CPO、硅光芯片 |
| **供电** | 独立供电系统成为主流 | 燃气轮机、备用电源需求扩容 |
| **存储** | 大容量内存供需缺口长期存在 | 存储硬件厂商、高速内存 |
| **连接器** | 绑定头部客户多线拓展 | 高速连接器、检测业务 |
#### 供需紧张环节清单
| 环节 | 紧张原因 |
|------|---------|
| 高端电路板基材 | AI服务器需求拉动，供不应求 |
| MLCC（大容量） | 服务器功耗越高配套越多，产能转向高端 |
| 光纤光缆 | 海外芯片厂商合作扩产仍不足，海外供不应求 |
| 算力租赁 | 供需持续紧张，价格稳步上行 |
| 大容量内存 | 供需缺口长期存在 |
| 碳化硅 | 从过剩转紧缺，景气上行 |
| 陶瓷原材料 | 海外供货收紧，AI配套需求+供给集中 |
#### 国产替代进展
| 领域 | 验证信号 |
|------|---------|
| 算力芯片 | 国有银行批量采购入围；新一代昇腾芯片即将量产 |
| 开源大模型 | 原生适配国产算力芯片 |
| 半导体设备 | 海外管控→自主替代加速 |
| 半导体材料 | 光刻胶、面板配套材料本土替代窗口 |
| 陶瓷材料 | 海外供货波动→本土窗口 |
#### AI投资ROI周期
**关键判断**（2026.07，谷歌Q2财报后）：
- 产业从"上半场看Capex"转向"下半场看ROI"
- 上游硬件利润逻辑清晰，受冲击较小
- 软件厂商可能是应用端最早赚钱的一批
- **"不要博弈消息表面，消息看上去好不一定是利好"**

### 1.4 物理AI（机器人+自动驾驶）
| 时间 | 阶段 | 关键节点 |
|------|------|---------|
| 2026H2 | 验证期 | 自动驾驶规模化、机器人批量生产启动 |
| 2027 | 放量期 | 工业/电力标准化场景优先落地 |
| 2028 | 规模化 | 具身智能模型成熟，通用机器人进入家庭/商业 |
**核心卡点**：真实场景数据不足、仿真与现实适配差距、推理延迟、算力成本偏高
**投资框架**：
| 层次 | 方向 | 代表机会 |
|------|------|---------|
| 数据层 | 真实场景仿真数据 | 数据基础设施服务商 |
| 模型层 | 具身智能模型 | 2028年规模化节点 |
| 硬件层 | 核心零部件 | 高扭矩电机、灵巧手、减速器 |
| 检测层 | 机器人检测方案 | 工业检测设备企业 |
| 材料层 | 轻量化合金 | 金属铸造企业合作 |
### 1.5 A股科技内部轮动规律
**"喜新厌旧"迁徙模型**：资金不断从老方向向新方向迁徙
**典型路径（2026年5-7月）**：
```
光模块/PCB（年初主线）
→ PCB往细分切（数纸材料、铜箔等上游）
→ 光往上游切（光纤等）
→ 存储
→ MLCC（高端电容）
→ 载板
→ 功率半导体
→ SoC
```
**操作含义**：
- 老方向即使业绩超预期，市场也觉得"没有新鲜感"
- **跟随资金迁徙：从大板块往细分新方向切**
- 老科技即使反弹也要做相应控制
### 1.6 光模块深度分析（三维择时案例）
| 维度 | 结论 |
|------|------|
| 拥挤度 | 光模块回落至-1.5x标准差以下（与去年4月和10月相当）→ **底部区间** |
| 龙头比价 | A股北美算力链与国产算力链龙头比价已回落至去年6月行情启动时水平 |
| 海外映射 | 7月以来美股"光"相对半导体存储已率先企稳 |
### 1.7 美股"老灯/小灯"分化映射
| 美股信号 | A股映射 |
|---------|---------|
| "小灯"（半导体/存储）跌 | A股存储/半导体/光模块承压 |
| "老灯"（大型科技）涨 | A股大盘价值/科技应用相对稳定 |
**核心**：不是简单的"美股跌A股跌"，而是看**美股哪个方向跌**。

## 二、周期与资源品
### 2.1 有色金属定价
**有色3x成本定价法**：供给零增量品种，稳态价格 = 完全成本 × 3
| 品种 | 十年产量CAGR | 状态 |
|-----|-------------|------|
| 钨、钼、锑 | 负增长 | 已验证3x |
| 锡 | 0.5% | 待验证 |
| 铜 | 2% | 低增量 |
**铜铝比**：当前4.2 vs 常规3.3-3.7，铜铝比偏高时铝存在补涨空间。
### 2.2 人民币升值配置逻辑
**历史规律**：汇率趋势性升值对应牛市主升段（如2017年漂亮50行情、2020年新能源大涨行情）
**配置优先级**：
| 优先级 | 方向 |
|-------|------|
| 1 | 外资审美变迁+景气成长：AI硬件、优势制造业、有色 |
| 2 | PPI上行+进口成本下降：钢铁、化工 |
| 3 | 购买力提升：免税、电商、酒店餐饮 |
| 4 | 估值合理+成本端受益：航空机场、造纸、物流 |
### 2.3 钢铁行业周期判断
**景气低点介入信号**：
- 全行业不盈利或亏损
- 短期价格与成本倒挂
- 宏观紧缩政策趋于放松
- 社会库存量极低
- 公司股票破净
**接近景气高点抛出信号**：
- 行业盈利剧增
- 经济增速过快可能招致调控
- 价格高涨影响下游需求
- 经销商大量囤积钢材

## 四、宏观策略与市场节奏
### 4.1 量化时代的市场特征
**传统经验失效清单**：
| 失效经验 | 内容 |
|----------|------|
| 连续提估值不超3年 | 已突破 |
| 行业"事不过三" | 已突破 |
| 机构持仓20%见顶 | 已突破 |
| TMT成交占比40%上限 | 已突破 |
**核心警示**：**量化主导时代，传统技术分析和经验规律不再可靠，"少预判多跟随"**
### 4.2 量化因子触发链（暴跌分析）
```
海外市场异动（韩股跌9%）
→ 量化因子共振
→ 无差别杀跌（1300余家跌超7%）
→ 流动性冲击
→ 大批流动性错杀标的率先修复
```
**关键判断**：
- 暴跌由量化主导，内外无实质利空 → 属于流动性冲击而非基本面恶化
- 量化杀跌后的修复行情往往**快速且剧烈**
- 事件驱动型炒作退潮典型：航天板块周五高潮→周一反埋
### 4.3 春季躁动节奏
| 时间 | 特征 |
|------|------|
| 11月 | 与基本面相关性最弱 |
| 12月 | 基本面定价有效性逐步加强；大盘、低估值占优 |
| 春节前2个交易日 | 平均启动时间 |
| 春节至两会前 | 小盘、科技成长明显占优 |
| 持续约20个交易日 | 平均持续时间 |
**风格规律**："价值搭台，成长唱戏"
**重要例外**：若某一风格在12月占优，那么其优势在次年1月仍将延续。
### 4.4 业绩披露窗口节奏
| 时间 | 策略 |
|-----|------|
| 1月上半月 | 聚焦业绩确定性品种 |
| 1月下半月 | 业绩预告密集披露，部分个股面临验证压力 |
| 2月 | 数据空窗期，弹性增大，可关注主题投资 |
| 3月 | 预期和想象力主导，聚焦产业趋势 |
### 4.5 风格日历效应
**一般规律**：12月和1月，成长与小盘风格从超额收益和胜率维度均不占优
**重要例外**：**若某一风格在12月占优，那么其优势在次年1月仍将延续**
**核心原因**：12月占优的风格 = 确立了景气优势，景气优势在年报业绩预告中有望进一步验证
### 4.6 牛市终结信号判断
**核心**：多维度同时触发 → 牛市终结概率大
| 信号维度 | 终结信号 | 当前状态（2026.07） |
|---------|---------|------------------|
| 估值 | 股权风险溢价下破-2σ | 处于均线附近，未终结 |
| 交易 | 成交额超越前四轮峰值倍数 | 仅超越2017年水平 |
| 资金 | 开户数高峰+融资+2σ+爆款基金 | 未确认 |
| 量能 | 持续缩量跌破关键水平 | 维持3万亿以上，未终结 |
**结论**：成交维持3万亿以上 = 风偏犹在，牛市延续信号
### 4.7 大型IPO流动性虹吸
**节奏规律**：
| 阶段 | 操作 |
|------|------|
| IPO上市前 | 控制仓位，不急于加仓 |
| 上市后1-2天 | 最恐慌时刻，也是最后洗盘 |
| 快则1-2天、慢则一周 | **确定性最高的进场时机** |

## 五、新能源与电力设备
### 5.1 光伏行业
- 供给侧改革稳步落地，头部平台企业逐步成型
- 关注全球新增装机量和硅料价格
### 5.2 储能
- 储能电池龙头签订三年长期供货大单
- 户用储能产品受益于能源数字化需求
- 上游电池原材料稳定供应成为行业核心关注点
### 5.3 风电
- 海上风电产业链：塔桩、铸锻件、电缆
- 风机企业短期利润承压，后续反转确定性大
### 5.4 电力设备
- 电力设备企业面向算力机房的配套电源产品取得技术突破
- 进入海外头部算力硬件厂商供应链
- 三大投资方向：低碳能源、电网升级、轨道交通

## 七、实战案例库
### 案例1：Meta出售算力事件——"利空实质利好"
| 要素 | 内容 |
|------|------|
| **事件** | Meta拟布局AI云业务对外出售算力 |
| **市场担忧** | 大厂资本开支落幕 |
| **实质判断** | 即便Meta退出也不改变AI硬件需求紧缺现状，反而强化预期 |
| **类比** | 康宁玻璃桥事件：看上去利空实质是加速行业扩张 |
| **推论** | 推理需求井喷→算力出租是最好现金流→反推材料更具备稀缺性 |
| **操作** | 光、PCB等方向会有修复预期 |

## 八、市场情绪与资金面判断
### 8.1 资金分层观察
| 资金类型 | 含义 |
|---------|------|
| 机构流入 | 中长期看好信号 |
| 主力流入 | 短期做多意愿 |
| 大户流入 | 中等资金看多 |
| 散户流入 | 市场情绪偏热（反向指标） |
**关键**：当机构/主力/大户/散户方向分歧时，市场容易震荡。
### 8.2 "共振"判断行情质量
| 共振类型 | 行情质量 |
|---------|---------|
| 海外链+国产替代+大金融同步走强 | 高质量行情，赚钱效应好 |
| 仅单方向走强 | 结构性行情，赚指数不赚钱 |
| 多方向均无共振 | 弱市，控制仓位 |
### 8.3 板块持续性判断
**走出持续性的方向特征**：
- 获得资金持续流入
- 逆势走强（大盘跌时抗跌）
- 调整后被快速修复（错杀修复）
**事件驱动退潮特征**：
- 周五高潮→周一反埋
- 近月未成新主线
- 缺乏业绩支撑
### 8.4 拥挤度+龙头比价+海外映射三维择时
**光模块案例验证**：
1. 拥挤度回落至底部 → 风险释放
2. 龙头比价回落至行情启动水平 → 性价比凸显
3. 海外映射企稳 → 催化确认
4. **三维共振 → 布局信号**
### 8.5 关键量能参考
| 量能 | 市场状态 | 仓位建议 |
|------|---------|---------|
| >3万亿 | 牛市特征，高风偏 | 7-8成 |
| 2.5-3万亿 | 活跃水平 | 6-7成 |
| 2-2.5万亿 | 正常水平 | 5-6成 |
| <2万亿 | 缩量低迷 | 3-4成 |
### 8.6 风险提示的反向信号
- 大批个股集中发风险提示 ≠ 见顶
- **震荡分歧后往往再创新高**
- 量化时代的降温信号需要更大强度才有效
