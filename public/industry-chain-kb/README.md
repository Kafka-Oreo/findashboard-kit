# industry-chain-kb（产业链知识库，数据目录占位）

此目录用于存放「产业链问答」模块（`/api/industry-chain-qa`）的知识语料，
原项目内容（课程语料等）因版权原因未随模板分发。

目录约定：

```
industry-chain-kb/
├── 01_产业链方法论/     # 方法论文档（Markdown）
├── 02_行业语料/         # 按行业组织的问答语料
└── README.md
```

语料为 Markdown 文本，路由会扫描目录并在服务端拼接后注入 LLM 上下文。
放置你自己的语料后，周报页的「产业链问答」即可使用。
