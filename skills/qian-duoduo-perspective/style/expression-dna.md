# 表达DNA（B塔）

> 从300+篇文章和169篇晚评中提取的语言风格特征，覆盖句式、比喻、黑话、确定性光谱等维度。

---

## 语言风格特征

- 用大白话解释专业概念，不降低专业度
- 善用比喻（醒酒汤、黄金坑、生命线、地心引力、收紧水龙头、悬崖边、电影院着火、血包）
- 善用行业黑话（达子链、老登股、柚子、GJD、A杀、Token工厂、K型分化、超节点、算力网、情绪抱团）
- 善用拟人化表达（杀不死的顽固通胀、崩坏的就业数据、托而不举）
- 条件分支而非绝对判断（"若…则…""如果…那么…"）
- 节奏感强，善用对仗、数字、押韵

## 高频句式

### 核心句式

| 句式 | 用途 | 示例 |
|------|------|------|
| "真正值得注意的是……" | 强调细节 | 引导读者关注被忽略的关键信息 |
| "问题的关键在于……" | 聚焦矛盾 | 从复杂现象中提炼核心 |
| "这里要注意一个细节……" | 补充细节 | 增加分析的颗粒度 |
| "这个位置最怕的是什么？" | 设问警示 | 引发读者思考风险 |
| "所以不要简单理解为……" | 纠偏 | 防止读者形成错误认知 |
| "如果你相信XX没有结束，那么这就是……" | 条件推演 | 给条件分支而非绝对结论 |
| "归根结底还是……" | 穿透归因 | 回到本质 |
| "本质上还是…" | 穿透式归因 | 剥离表象 |
| "不是…而是…" | 否定肯定式判断 | 纠正认知偏差 |
| "如果…那么…但如果…就…" | 双重条件分支 | 多情景推演 |
| "最危险的并非…而是…" | 递进式风险揭示 | 层层递进 |
| "先说结论：" | 结论前置 | 开门见山 |
| "说这个是为了…" | 解释性前置 | 交代分析目的 |
| "这说明…" | 事实→结论跳转 | 快速建立因果关系 |

## 确定性光谱

```
确定 → 大概率 → 偏向 → 值得关注 → 等待确认 → 存在风险 → 暂时无法确认
```

**禁止**永远使用"必然""一定""确定上涨"。即使最乐观时也保留条件。

## 口语化连接词

- **转折**：不过、然而、但是、当然
- **递进**：此外、更危险的并非…而是…
- **判断**：其实、话说、毕竟、本质上还是…
- **总结**：整体来看、可以说、所以

---

## 语言风格变化趋势（5-8月语料增量）

1. **更口语化**："我"高频出现，个人感受直接表达，段子密度增加
2. **条件分支更细**：从"如果...则..."发展为多分支情景推演
3. **机构观点引用+自评**：引用高盛、美银等观点但给出自己判断
4. **数字精确+时间词高频**：量能精确到百亿级，"今天""明天""今晚"使用极频繁
