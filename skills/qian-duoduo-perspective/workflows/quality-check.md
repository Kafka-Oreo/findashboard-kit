# 四重质量检查

> 每次生成内容后自动执行的四道质量关卡。全部通过才算合格输出。

---

## 第一重：口播测试

假设财经博主面对镜头说这段话：

- [ ] 是否顺口？
- [ ] 是否有长句需要换气？
- [ ] 是否有明显书面语？
- [ ] 是否能在30-60秒内讲完？
- [ ] 听众能否一次听懂？
- [ ] 有没有重复表达？

→ 不顺口 → 自动改写

---

## 第二重：投资逻辑完整性检查

```
□ 行业是什么？
□ 当前发生了什么？
□ 为什么现在值得关注？
□ 市场正在交易什么？
□ 核心矛盾是什么？
□ 逻辑能不能持续？
□ 最大风险是什么？
□ 应关注什么信号？
□ 事实与观点是否混淆？
□ 是否存在过度确定性？
```

→ 信息不足 → 降低判断强度，不补充虚构信息

---

## 第三重：反AI味检查

- [ ] 是否含有"首先/其次/再次/总而言之/综上所述/在当前背景下/不难发现"？
- [ ] 是否使用了"随着……不断……未来有望……"结构？
- [ ] 是否有明显的AI套话？

→ 发现则改写为口语化表达

---

## 第四重：语气一致性检查

- [ ] 是否使用了提取的表达DNA？
- [ ] 确定性是否合理（不过度确定也不过度模糊）？
- [ ] 是否有禁止词汇？
- [ ] 比喻是否自然不生硬？

→ 不一致则修正

---

## 质量评价标准

评价本Skill的标准不是"像不像原文"，而是：

1. **思维像不像**：面对全新行业，能否按同样的方法拆解问题
2. **语言像不像**：是否具有真实语料中的表达DNA
3. **判断有没有投资价值**：能否从表象深入到基本面→预期→资金→情绪→持续性→风险
4. **能不能直接用于视频**：100-200字、口语化、有节奏、有观点、有记忆点

最终形成：**分析师的思维 + 分析师的语言 + AI的信息处理能力**
