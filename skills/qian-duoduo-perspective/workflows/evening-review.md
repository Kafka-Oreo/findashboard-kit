# 晚评模式（长文案）

> 当用户要求"写晚评""盘后复盘"时，切换为长文案模式，按四段式结构输出。

---

## 四段式结构

### 段落①：市场回顾 — "五要素开场"

1. **隔夜海外锚定**：先讲海外发生了什么，对A股影响
2. **当日大盘走势**：指数+量能三维分析（放量是增量还是存量腾挪、上午vs下午）
3. **情绪端状态**：涨跌家数+涨跌停+连板高度+晋级率
4. **关键背离分析**：指数vs情绪、大小票分化、K型分化程度
5. **一句话定调**：用关键数字锚定

示例："今天成交3.56万亿，上涨家数仅799只。"

### 段落②：板块方面 — "四层结构"

1. **主线分层**：分支1（最强）→ 分支2（次强）→ 分支3（补涨）→ 分支4（最弱/调整）
2. **承接方向**：方向A（主动承接）→ 方向B（被动防守）
3. **暗线/投机载体**：重组并购、次新等
4. **轮动逻辑总结**：用"海外链vs国产链""上游涨价vs中游制造vs下游应用""业绩驱动vs情绪驱动vs政策驱动""新登vs老登"等维度分类

核心区分：海外链vs国产链是算力方向核心分类维度。

### 段落③：海外市场 — "情景推演型"

1. **海外发生了什么**：美股+美债+地缘+韩股
2. **为什么涨/跌**：归因分析，非简单罗列
3. **关键变量识别**："今晚的关键是XX"
4. **多剧本分析**："现在市场有两个剧本在抢解释权"
5. **明日前瞻**：海外今晚怎么走会对A股产生什么影响

### 段落④：次日应对 — "精细化条件分支"

1. **多情景推演**：
   - 如果A发生 → 策略X
   - 如果B发生 → 策略Y
   - 如果C发生 → 策略Z

2. **具体观察指标**："看开盘30分钟科技是否走强""看某某方向的反馈"

3. **操作节奏** + 三不买原则 + 免责声明

---

## 晚评风格要求

- 口语化程度更高，"我"的出现频率高
- 数据和事实要精确到百亿级别
- 段落之间要有逻辑递进，不是简单罗列
- 每个判断都要有条件分支
- 结尾必须有免责
